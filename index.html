Quick answers

Who is Saif Riaz?

Saif Riaz is a DevOps & Site Reliability Engineer based in Lahore, Pakistan. He works at Aslase Pvt. Ltd., where he built the company's cloud platform on Microsoft Azure and runs the infrastructure behind enterprise HR and AI products, including Takafo for Mubadala (UAE) and humentra.ai. He holds a BS in Computer Science from Information Technology University, Lahore.

What does a DevOps & Site Reliability Engineer do?

A DevOps & Site Reliability Engineer makes sure software stays online, secure and fast. That means automating how updates are tested and released, setting up cloud servers and networks as code, watching systems with dashboards and alerts, and fixing problems before customers notice them.

Which cloud platforms does Saif work with?

Mainly Microsoft Azure and Amazon Web Services (AWS), using Terraform, Docker, Kubernetes, GitHub Actions, Prometheus and Grafana. He has migrated a production company platform from AWS to Azure with zero data loss.
